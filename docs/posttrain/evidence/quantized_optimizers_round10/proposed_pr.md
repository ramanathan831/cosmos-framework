# Share native eight-bit AdamW across SFT and action-policy construction with FP32 local-master recovery

BF16 action-policy parameters need an explicit update-precision owner before selecting quantized moments. This change extends the existing optional bitsandbytes0.49.2 backend with tracked FP32 masters for ordinary parameters and one-dimensional FSDP2 shards. It preserves final trainable identities, native parameter groups, compute precision, clipping and legacy defaults. Model weights are not quantized.

SFT retains its ordinary-FP32 path. An opt-in four-GPU GR00T/LIBERO recipe exercises the actual Joint PPO trainer, actor/value groups, rollout synchronization, simulator and completed-window checkpoint boundary. AlpaGym now reaches the same factory after native model setup, retaining its epsilon1e-6, betas, decay, LR/warmup and clipping. Its required external `alpagym_runtime.posttrain` API and resolved driving configuration remain unavailable; native Alpamayo training/recovery is **not complete**.

Distributed checkpoints preserve rank-owned masters, lazy moments, uint8 state and scales/maps. A byte-tensor envelope avoids large-object serialization limits and byte-string expansion while retaining older format readers. Restore validates identity before mutation and converges failures/rollback across ranks. Generation-bound collector receipts and fresh-process evaluation prevent publication after failed provenance checks. Server-synchronized metadata fixes a captured stale-timestamp disagreement without relaxing identity validation. Pending-validation recovery on the tested Lustre mount uses the original output root because atomic cross-directory no-replace promotion is unavailable.

Completed evidence includes:

- Two real A100 ranks: fused/nonpaged/paged reference and fresh-process continuation4→8; mixed BF16/FP32 storage, accumulation, clipping, unused/empty shards, rank-consistent nonfinite skip, corruption, generation changes, rollback and managed-owner release. All12 latest rank/phase receipts pass after the metadata fix.
- Four-GPU native GR00T: fused/nonpaged/paged8-update training, native100-case evaluations and durable checkpoints. Nonpaged/paged fresh reload matches every learner-state field; both continue4→8 with finite updates and new publication. Physical environments reset on resume, so these do not establish identical future simulator trajectories.
- Actual GR00T moments plus metadata fall from12,998,755,840 to3,304,438,792bytes:74.5788% less. Including the6,499,373,572bytes of FP32 masters present in both controls gives49.7192% less. Neither percentage is a total-device-memory claim.
- Three paired CPU checkpoint trials on an actual native rank state show3.98× roundtrip speed [3.50,4.45], with mean process peak PSS25.44→17.96GiB. This shared prepared-state result is not an optimizer or complete-workflow speed claim.
